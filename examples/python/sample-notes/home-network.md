# Home network

The router is in the hallway cupboard. The admin page is at 192.168.1.1.

The guest Wi-Fi is called "harbour-guest". Its password is on the card taped
inside the cupboard door. Change it every January.

The printer has a fixed address, 192.168.1.40. If it drops off the network,
turn it off, wait ten seconds and turn it on again before touching the router.

The Mac in the study runs the Estia engine on port 27200 for the whole house.
